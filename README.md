# Twitch Panels — Telegram Spoiler + AutoChat

Пользовательский скрипт для Twitch, объединяющий AutoChat, управление историей сообщений, поддержку эмоутов 7TV и Telegram-подобный эффект спойлера для изображений.

## Возможности

### AutoChat
- Боковая панель появляется при обнаружении доступного чата Twitch.
- Ручная и автоматическая отправка сообщений с настраиваемым интервалом.
- Учёт медленного режима и ограничений чата при планировании отправки.
- Случайное изменение интервала между автоматическими отправками.
- Live-превью сообщения перед отправкой.
- Ограничение длины сообщения — 500 символов.
- Дополнительная опция вставки невидимых символов.

### История сообщений
- Сохранение сообщений отдельно по каналам.
- Фильтрация истории по стримерам.
- Закрепление, редактирование, удаление и сортировка перетаскиванием.
- Несколько вариантов текста для одной записи.
- Быстрый предпросмотр и отправка сохранённых сообщений.
- Импорт и экспорт истории в формате JSON.

### Эмоуты 7TV
- Загрузка глобальных и канальных эмоутов 7TV.
- Поиск и вставка эмоутов через встроенное окно выбора.
- Отображение эмоутов в предпросмотре и истории сообщений.

### Telegram-style Spoiler
- Размытие изображений с анимированным слоем частиц.
- Возможность раскрыть изображение наведением или взаимодействием.
- Отдельные настройки включения эффекта и постоянного скрытия изображений.

## Установка

1. Установите менеджер пользовательских скриптов:
   - [Tampermonkey](https://www.tampermonkey.net/) — рекомендуется.
   - [Violentmonkey](https://violentmonkey.github.io/).
2. Нажмите кнопку **«Установить скрипт»** вверху страницы.
3. Подтвердите установку в менеджере скриптов.
4. Откройте или обновите страницу Twitch.

## Поддержка

Скрипт запускается на страницах `https://www.twitch.tv/*`.

## Данные и внешние сервисы

Настройки и история сообщений сохраняются локально в `localStorage` браузера. Для получения глобальных и канальных эмоутов 7TV, а также определения Twitch ID канала используются внешние API `7tv.io`, `decapi.me` и `api.ivr.fi`.
